### About

**g-makris.com** is a professional services platform and "Living Lab" for AI-powered web development and FinTech operations — built by [Gerasimos Makris](https://linkedin.com/in/gerasimosmakris).

The platform itself is the portfolio: a production-grade, serverless application demonstrating secure architecture, intelligent workflows, and transparent development practices.

### Tech Stack

| Layer | Technology |
|---|---|
| **Framework** | Next.js 16 · React 19 · TypeScript 5 |
| **Styling** | Tailwind CSS · Radix UI (shadcn/ui) |
| **Backend** | Firebase (Firestore · Auth · App Hosting) · GCP Serverless |
| **AI** | Google Genkit · Gemini |
| **Email** | Resend |
| **Infra** | Firebase App Hosting · IONOS (DNS) · GitHub Actions |

### Architecture Principles

- **Zero Trust Security** — Strict Firestore rules, passwordless auth (OAuth + magic links)
- **Serverless-First** — GCP + Firebase for enterprise-grade scalability at minimal cost
- **AI-Native** — Genkit-powered intelligent workflows for content delivery and data handling
- **Accessibility** — WCAG 2.1 AA target across all pages
- **Build in Public** — Transparent roadmap, system status, and version history
